# Practical Assignment: Build a Highly Available and Secure 3-Tier Cloud Environment

## Objective
Design and implement a secure 3-tier AWS architecture with separate web, application, and database layers, using networking and access controls to make the environment resilient and production-ready.

## Likely implementation flow
1. Create the VPC and subnet structure for public and private tiers.
2. Configure route tables, NAT, security groups, and network ACLs.
3. Launch the web tier instances behind a load balancer.
4. Launch the application tier with restricted access from the web tier.
5. Deploy the database tier in the private layer with only required access.
6. Add monitoring, health checks, and security hardening to complete the design.
